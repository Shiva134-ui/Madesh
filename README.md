## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/Shiva134-ui/portfolio.git
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build

```bash
npm run build
```
